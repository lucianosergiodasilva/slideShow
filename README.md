# SlideShow Infinito

Este projeto é um Slideshow simples desenvolvido para fins de estudo, baseado no tutorial do canal **LexterXPS**.

## 🚀 Sobre o Projeto
Este é um caso de estudo focado na criação de uma interface de exibição de imagens dinâmica. O objetivo principal foi praticar a lógica de manipulação do DOM e transições de estilo.

## ⚙️ Como o projeto funciona
A aplicação exibe imagens de forma sequencial. No HTML, apenas a primeira foto é declarada, enquanto todas as demais são carregadas e gerenciadas dinamicamente via JavaScript. 

O diferencial deste projeto é a **rolagem infinita**: ao chegar na última imagem, o sistema retorna automaticamente para a primeira, criando um loop contínuo de visualização.

## 🛠️ Problema que ele resolve
Ele oferece uma solução leve e funcional para exibição de portfólios ou galerias de fotos em sites, eliminando a necessidade de bibliotecas externas pesadas para carregar carrosséis simples.
